# M2 存储与认证验收记录

2026-09-21 按 [M2 退出条件](../milestones.md#阶段与依赖) 完成存储与认证实现；[AC-02](../quality.md#ac-02-认证与凭证)、[AC-03](../quality.md#ac-03-持久化) 对本阶段能力的检查通过。本文记录实际验证结果，不替代后续阶段的生产入口和部署验收。源码链接跟随现行 Minimal API 文件；M3 的资源管理与真实读取验证见 [M3 验收记录](m3.md)。

## 环境与实现范围

- Windows、.NET SDK 10.0.400；EF Core SQLite、Design 和 ASP.NET Core 测试宿主使用集中依赖中的 10.0.12；`xunit.v3.mtp-v2` 包为 4.0.1，测试框架为 xUnit v3、运行平台为 MTP v2。
- [Persistence](../../src/backend/Trelix.Server/Persistence/TrelixDbContext.cs) 包含项目、环境、文件草稿、发布记录、单管理员、管理员会话、应用令牌及环境授权。启动时应用初始迁移；时间存储为 UTC INTEGER ticks，文件与令牌使用应用维护的并发标记。
- [管理员认证](../../src/backend/Trelix.Server/Features/Authentication/AuthenticationEndpoints.cs) 提供防伪造令牌、登录、会话查询和退出；使用 PasswordHasher、HttpOnly Cookie、固定 8 小时会话、服务端失效校验及登录限流。
- [令牌管理](../../src/backend/Trelix.Server/Features/ApplicationTokens/ApplicationTokenEndpoints.cs) 提供创建、分页与单个查询、撤销和原子轮换。256 位随机凭证只在签发响应返回，持久化 SHA-256 摘要；有效期必填，支持多个明确的项目/环境组合。
- 通用异常捕获位于 [Core](../../src/backend/Trelix.Core/Middleware/SafeExceptionHandler.cs)，业务错误映射和认证授权位于 Server；ServiceDefaults 的遥测注册未重复引入。

## 覆盖边界

- 本轮验证管理员与令牌管理的实际 HTTP 入口；应用令牌认证及资源授权通过仅注册于测试宿主的探针验证。项目/环境管理、应用读取和长轮询尚未接入生产 API，需分别在 M3、M5 对真实入口重新验收；本轮不宣称应用已可读取配置或草稿隔离已端到端验收。
- 配置草稿、发布记录和并发标记在存储层验证；项目管理、保存、发布、历史与回滚业务 API 属于 M3，存储模型测试不表示这些用例已实现。
- 重启验证是进程内宿主销毁与重建、数据库和密钥重开，覆盖持久化与初始化逻辑；没有执行操作系统进程崩溃、Linux Docker 容器重建、备份恢复或真实 TLS 终止验证，这些属于 M6。
- 管理界面仍为 M1 应用壳，登录、令牌管理和编辑工作区在 M4 接入。本轮没有修改 Vue 业务组件，不把后端构建作为浏览器验收。
- 全链路生产遥测与信息边界验收仍在 M6；本轮仅验证所覆盖认证/异常请求中的日志与响应，不将其等同于完整 AC-10 验收。

首次启动配置、目录持久化和 API 调用顺序见 [本地开发](../local-development.md#server-存储与首次初始化)；部署约束见 [生产部署](../deployment.md)。
