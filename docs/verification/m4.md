### 登录后的实际操作

使用单独的合成验收项目、环境和文件执行以下流程，未使用真实业务配置：

- 从空资源树创建项目、环境及两个文件，资源位置、草稿修订和当前发布可见。
- JSON、YAML、Tree 转换保持对象、数组、字符串、数字、布尔和 null；YAML 注释与锚点名称被丢弃，别名展开后的值保留。
- 无效 JSON、YAML 和 Tree 数字输入后立即保存、发布或切换表示均被阻止，当前输入保留。有效文本输入后立即发布，先保存新草稿再发布。
- Tree 数值修改后发布，历史正文反映新值；回滚旧历史生成更高发布版本并标注来源，草稿修订不变；单独保存不改变当前发布版本。
- 两个页面从同一草稿修订编辑，后保存的旧页面收到冲突提示，保留当前文本并提供重新载入入口。
- 未保存文件切换时取消确认保留当前输入，确认后载入目标文件；Monaco 撤销恢复原正文，侧栏折叠后编辑区尺寸随容器变化。
- 应用令牌指定验收环境和未来有效期创建，签发及轮换均出现一次性凭证窗口；轮换后原令牌已撤销，随后撤销后继，列表确认有效令牌数为零。未复制或保存令牌原文，验收资源及撤销记录保留。
- 另一页面退出同一会话后，编辑页保存收到 401；重新登录后原未保存正文仍在。
- 缩小浏览器后实际页面宽度约为 785 CSS 像素，未发现横向溢出；浏览器工具未达到请求的手机宽度，因此不将此项记为手机窄屏通过。

### 发现并修复的问题

- Tree 曾对 Vue 代理直接执行 `structuredClone`，导致修改未同步。改为先 `toRaw`，重新编辑、发布并核对历史正文通过。
- Tree 的不完整数字和未完成属性名输入纳入统一校验，避免保存上一份有效数据；数组项可删除，对象属性写入支持特殊键名。
- 未保存、回滚、退出及撤销确认统一使用 Element Plus；资源提交失败保留表单输入，防止重复提交。
- 资源列表按分页完整读取，资源读取响应检查当前选择及取消信号；组件卸载取消请求并释放编辑器，具体释放行为仍须专项观察。
- YAML 解析异常统一转换为不包含正文的提示，401/403 使用中文状态说明。
- 新建和重命名曾共用当前资源的初始值，导致新建默认重名；现仅重命名预填，新建项目、环境与文件留空。
- 主导航展开与收起入口采用侧栏底部独立工具区与图标按钮，页面滚动时保持可见；窄屏收起后保留图标栏与底部展开入口。底部固定开关模式参考 [Ant Design 侧栏实现](https://github.com/ant-design/ant-design/blob/master/components/layout/style/sider.ts)，沿用现有 Element Plus 图标与原生按钮实现。
- 资源操作按层级归位：项目新增、重命名和删除位于项目标题旁，环境对应操作位于环境标题旁；统一使用带可访问名称和悬停提示的图标按钮，加载期间禁用。
