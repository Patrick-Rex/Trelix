### 浏览器操作与观测

开发页面和生产预览分别执行：

1. 桌面视口检查侧边栏、顶部栏、工作区空状态，以及项目/环境未选择提示。应用令牌入口和环境选择均禁用，未出现可执行的业务占位操作。
2. 点击收起侧栏，再通过 Enter 展开、Escape 收起；按钮的 `aria-expanded` 与可见状态一致。
3. 刷新后按 Tab 聚焦“跳转到主内容”，按 Enter 后焦点进入 `main-content`。
4. 在 320 × 740 视口刷新，侧栏默认隐藏，展开与 Escape 收起均有效；展开前后页面 `scrollWidth` 与视口宽度均为 320，无横向溢出。桌面检查宽度为 1280。
5. 查看页面和浏览器诊断，布局及空状态正常；检查完成后恢复浏览器视口。

## 覆盖边界

M1 联调使用 ServiceDefaults 的 Development 健康检查验证前后端通信；页面尚无业务 API 调用。没有将构建、类型检查或浏览器人工验收算作自动化测试套件，也未运行或声称通过尚不存在的 .NET、组件或端到端测试。

Core 的异常处理和序列化组件、Server 业务模块、持久化与认证、编辑器、SDK、示例及生产容器按后续里程碑接入。前端生产预览仅验证构建产物，不覆盖 Linux Docker、Server 静态资源集成或生产部署验收。
