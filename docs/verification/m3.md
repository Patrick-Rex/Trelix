# M3 配置发布 API 验收记录

2026-09-22 按 [M3 退出条件](../milestones.md#阶段与依赖) 验证配置发布 API；覆盖 [AC-04](../quality.md#ac-04-配置发布)、[AC-05](../quality.md#ac-05-并发与事务) 的存储与事务部分，以及 [AC-06](../quality.md#ac-06-应用读取与监听) 的读取部分。

## 环境与实现范围

- Windows、.NET SDK 10.0.300、真实 SQLite 文件、WebApplicationFactory、xUnit v3 与原生 MTP；依赖沿用集中版本，没有新增 NuGet 包。
- 管理 API 统一使用各 Features 模块的 Minimal API Endpoints，保留原认证、令牌路由与响应契约，使用内置验证、统一安全 Problem Details 和管理写操作防伪造中间件。
- [项目环境](../../src/backend/Trelix.Server/Features/Projects/ProjectService.cs) 实现创建、分页、读取、重命名与空资源删除；[文件草稿](../../src/backend/Trelix.Server/Features/ConfigFiles/ConfigFileService.cs) 实现文件管理、草稿保存与整文件原子删除；[发布服务](../../src/backend/Trelix.Server/Features/Releases/ReleaseService.cs) 实现发布、历史、回滚和数据库并发保护。
- [应用读取](../../src/backend/Trelix.Server/Features/Distribution/DistributionService.cs) 实时核验项目环境授权，从同一发布记录返回正文、文件 ID、版本及时间，不读取草稿。
- [配置发布迁移](../../src/backend/Trelix.Server/Persistence/Migrations/20260922095541_ConfigurationPublishing.cs) 增加项目环境并发标记并初始化旧数据，调整回滚来源外键的删除检查时机；不删除既有配置和历史。

## 验证结果

执行入口统一见 [Server 自动化测试](../local-development.md#server-自动化测试) 和 [Server 构建](../../src/backend/Trelix.Server/AGENTS.md#验证)。测试构建输出仅提取 error；失败详情和测试统计照常核验。

完整测试结果为 **Passed: 80, Failed: 0, Skipped: 0**，退出码 0；包含原有 42 项及新增 38 项场景。最终 Server 显式构建退出码 0，无 error。交付时检查 48 个新增或修改文件与 261 个本地文档链接，UTF-8 无 BOM、LF、末尾换行、链接及章节锚点均通过，`git diff --check` 通过。

## 覆盖边界

- M3 不实现通知等待者、长轮询与 SDK。发布通知、取消、超时和等待期间撤销的完整验收仍属 M5；本轮不宣称通知已交付。
- 重启验证覆盖进程内宿主重建和真实 SQLite 重开；Linux Docker、进程崩溃、备份恢复及生产静态资源交付仍属 M6。
- 管理界面仍为应用壳，本轮未修改 Vue 组件或进行 M4 浏览器业务验收；前端构建不是本轮交付结论。
- 性能未做基准测试，不宣称延迟或吞吐提升；分页、正文大小与深度具有明确上限，事务内不等待客户端或外部 I/O。

调用路径、字段、并发基准和删除影响见 [配置管理与应用读取](../local-development.md#配置管理与应用读取)；样例见 [Trelix.Server.http](../../src/backend/Trelix.Server/Trelix.Server.http)。
