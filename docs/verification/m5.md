# M5 .NET SDK 与监听验收记录

2026-09-23 在 Windows、.NET SDK 10.0.400、`net10.0` Release 环境完成 M5 验收。Server 的 96 项、SDK 与示例的 39 项 xUnit v3 / 原生 MTP 测试全部通过，失败与跳过均为零；覆盖 AC-05 的通知部分、AC-06 和 AC-08。M4 尚未完整通过 AC-07，此记录不扩大其完成结论；Linux 容器交付与恢复验收仍属于 M6。

## 自动化行为证据

- [Server 监听测试](../../tests/Trelix.Server.Tests/DistributionWatchTests.cs) 使用正式 HTTP 路由和独立 SQLite。验证发布与回滚通知、草稿无通知、SQLite 触发器注入事务失败后无通知、通知丢失及抛错后的持久化补查。注册前的受控同步点在真实 SQLite 提交新版本，验证检查与注册之间的竞态。
- 同组测试覆盖缺失与错误凭证、管理员 Cookie 不可替代令牌、跨项目及同项目跨环境隔离、等待期间撤销/过期/授权移除、非法发布身份、删除与同名重建。等待前捕获的 DbContext 均已释放；正常超时、请求取消、服务停止、容量 503 和其他文件通知均检查等待者清理。既有读取与认证测试随 Server 全套回归。
- [SDK 测试](../../tests/Trelix.Extensions.Configuration.Tests/ConfigurationTests.cs) 覆盖两种现代宿主、原 IConfiguration 保留、默认配置优先级、本地节与代码覆盖、固定参数副本、特殊名称和地址路径前缀、重复注册及配置源重建。User Secrets 优先级通过相同类型的隔离 JSON 源验证，不读取开发机真实机密。
- 首次 401/403/404/500、传输错误、超时、过大响应、无效身份和正文均拒绝接入并释放 HTTP 客户端；错误及日志不包含注入的敏感正文。JSON 检查覆盖 1 MiB、64 层的合法边界与越界、根对象、重复属性、冒号属性、非法 Unicode、null、空数组、嵌套数组及大小写无关键。
- 运行期故障保留最近配置；完整替换移除旧键，重复版本不重载，同文件旧版本不能回退。文件 404 期间保持配置，同名新文件可从版本一继续接入。正常 204 立即继续监听；[受控定时器](../../tests/Trelix.Extensions.Configuration.Tests/ControlledTimeProvider.cs) 验证退避到期才重试及停止取消退避；停止和未启动宿主的释放均关闭传输。
- [独立示例集成测试](../../tests/Trelix.Extensions.Configuration.Tests/SampleIntegrationTests.cs) 启动真实 Kestrel Server 与示例，通过正式管理入口发布后验证 IConfiguration、IOptionsMonitor 和新请求作用域 IOptionsSnapshot 更新。关闭 Server 后等待 SDK 的实际失败信号，确认保留最近配置；用同一 SQLite 和密钥目录重启 Server，再发布并确认恢复更新。
- [AppHost 测试](../../tests/Trelix.Extensions.Configuration.Tests/AppHostTests.cs) 验证示例默认关闭，以及启用后独立 Server/Sample 进程的连接注入和健康检查等待。测试先发布并签发随机测试凭证，再启动示例；前端及 npm 安装资源显式不启动，避免干扰已有开发实例。

测试同步使用请求/响应握手、等待注册信号、Options 变更信号和受控定时器。超时用于被测行为或失败上限，不以任意延时推断竞态已发生。真实重启恢复验证位于 SDK 的跨模块示例测试中，不以进程内通知历史代替数据库结果。

## 连接片段与操作验证

临时 Vite 页面直接挂载管理端实际 `ConnectionConfigButton`，在浏览器点击复制连接配置。预览 JSON 的五字段正确，令牌为占位符；读取该预览，将片段地址和名称交给真实示例，应用令牌由外部注入，示例成功返回已发布的有限字段。此检查验证组件生成内容能够被 SDK 消费，不把工具虚拟剪贴板当作原生剪贴板粘贴核对，也不替代 M4 的完整编辑工作区验收。

解决方案 Release 构建退出码为 0；SDK `dotnet pack` 成功生成独立 NuGet 包，包内包含 net10.0 程序集、XML 文档和 README，未执行公开发布。前端类型检查通过，npm 清单及锁文件没有变化。执行命令统一见 [本地开发](../local-development.md#sdk-与示例自动化测试)，SDK 使用与打包说明见 [SDK 说明](../../src/sdk/Trelix.Extensions.Configuration/README.md)。
